セットの設定

話者

名前を変えると、その話者のすべての字幕と書き出しファイル名 （<名前>.話者X.srt の X）が一緒に変わります。 「適用して保存」を押すと、settings.json（名前と色）と edit.json（字幕側の話者）を両方まとめて保存します。 右上の「保存」を別途押す必要はありません。

レーンの並びは上から順です。「不明」は常に最後になります。

残っている版

いま編集しているのは edit.json です。それとは別に、 性質のちがう版を残しています。あとで 「文字起こしがどこを間違えたか」を突き合わせるための材料です。

wfp を取り込むと edit.json は差し替わります。その直前に手作業版を 自動で退避しますが、やり直したいときはここから置き直せます。

この動画に出てくる固有名詞

店名・地名・商品名・人名など、耳慣れないので化けやすい語を 1 行に 1 つ書きます。 次に文字起こしをするときの手がかりになり、この表記で書かれやすくなります。 すでにある字幕は変わりません。

文字起こしの設定

Gemini を使う / 使わない

Gemini は有料です（3.6 Flash の実測でおよそ 1 時間の動画あたり $2）。 キーを入れただけでは動きません。使うときにここで「使う」に切り替えます。 押し間違いで課金されるのを防ぐための切り替えなので、 終わったら「使わない」に戻しておくのが安全です。
無料で済ませたいときは Gemini を使わず、先にローカルで文字起こししてください （python -m traccia transcribe 動画.mp4 --diarize）。

API キー

Google AI Studio で取得したキーを入れます。 保存先は ~/.traccia/config.json で、 本人だけが読める権限で書きます。素材フォルダには入りません。 環境変数 GEMINI_API_KEY があれば、キー未設定のときはそちらを使います。

    マウス操作
    ブロック本体をドラッグ＝字幕全体を移動 ／ 左右の端をドラッグ＝開始・終了だけを移動 ／ 上下のレーンへドラッグ＝話者を変更。Alt を押しながらドラッグするとスナップを一時的に切ります。

    拡大縮小と表示位置
    タイムラインの上でホイールを回すと、カーソルの位置を軸に拡大・縮小します（上へ回すと拡大）。 トラックパッドのピンチも同じです。
    表示位置を動かすには、字幕のない余白を右ドラッグします（カーソルが手になります）。 中ボタンドラッグ、Alt+左ドラッグ、⇧＋ホイール、ホイールの左右でも動きます ── トラックパッドなどで右ドラッグが効かない環境では Alt+左ドラッグを使ってください。
    レーンが画面に収まらないときの縦スクロールは Alt＋ホイールです。

    タイムラインが全体表示のときは、表示範囲が動画全体と同じなので位置を動かせません。 先に拡大してください。

    まとめて選ぶ
    ⇧クリック＝直前に選んだものからの範囲 ／ ⌘クリック＝1件ずつ追加・解除 ／ 左のレーン見出し（話者A など）をクリック＝その話者を全選択。
    選んだあと Alt+1…9 で話者をまとめて付け替えられます。誤判定が固まっているときはこれが一番速い方法です。

    字幕を足す
    3 つの入口があります。どれも本文は空で作られ、そのまま入力できます。 長さは、キーとリストの「+」が 2 秒、タイムラインのダブルクリックは 画面上で 40px ぶん（倍率が変わっても掴める大きさを保つため）です。

    • A キー — 選択中のブロックの終わりから、同じ話者で足す。選択が無ければ再生位置から
    • タイムラインの空きをダブルクリック — そのレーン（＝その話者）のその位置に足す
    • リスト右端の「+」 — その行の終わりから、同じ話者で直下に足す

    同じ話者のブロックと重なる場合は作らずに警告を出します。長さを勝手に詰めることはしません。 別の話者と時間が重なるのは、同時発話としてありうるので許可しています。

    注意マーク
    自動チェックが、人が見て判断した方がよい箇所に付ける印です。リストの右側に出ます。 誤りとは限りません。各マークにカーソルを合わせるとその行の具体的な数値が出ます。 種類はリスト見出しの ! にカーソルを合わせても確認できます。

    • 同じ話者の中で重なっている — 必ず直す
    • 別の話者と重なっている — 同時発話ならそのままでよい
    • 表示速度が速すぎる（9字/秒 超）— 尺を伸ばすか S で分割

    時間の下の秒数が黄色のときは、尺が極端という意味です（0.4秒未満、または 12秒超）。 抽出ミスが残っている箇所の目印になります。

    目印
    リストの行頭の番号をクリックすると、その字幕に目印が付きます。もう一度で外れます。 意味は決めていません。「あとで見直す」「ここまで編集済み」など、そのとき決めて使ってください。 複数選択した状態で番号を押すと、選んだぶんをまとめて切り替えます。
    目印の付いた行は背景が変わり、タイムラインのブロックにも印が出ます。 リスト見出しの「印 N」を押すと、目印の付いた行だけに絞り込めます（本文検索と併用できます）。 目印は edit.json に残りますが、書き出す .srt には入りません。

    2 行の字幕
    本文の編集中に ⇧Enter を押すと改行が入ります。リストとプレビューのテロップに そのまま 2 行で出て、書き出した .srt も 2 行になります。 タイムラインのブロックは 1 行しか入らないので、改行は ⏎ で表しています。
    空行は作れません。⇧Enter を続けて押しても 1 つの改行にまとめます。 .srt は空行を字幕の区切りに使うため、空行が入ると書き出したあとに本文が失われるからです。

    作業時間
    編集にかけた時間を裏で記録しています。常時は表示しません。 右上の「設定」→「作業時間」で開くと、動画長・字幕数・話者数と並べて見られます。 次の仕事を見積もるときの目安に使えます。 数えるのは実際に手が動いていた時間だけで、最後の操作から 120 秒が過ぎたあと、 タブが隠れているあいだ、動画を再生しているあいだ、文字起こしの待ちのあいだは数えません （再生・停止の操作そのものは数えます）。左の点が光っているときが計測中です。

    削除の確認
    本文の入った字幕を消すときは、何を消すのか見せてから確認します。 本文が空の字幕は、確認せずにそのまま消えます（失うものが無いため）。 数をこなすときに毎回聞かれるのが煩わしければ、右上の「設定」→「編集の設定」で 確認せずに削除するに切り替えられます。切り替えはこの PC に残ります。 確認を出さない設定でも、消したものは ⌘Z で戻せます。

    文字起こし
    上の「文字起こし」で、いま開いているセットを Gemini に書き起こさせます。 有料です（3.6 Flash の実測でおよそ 1 時間の動画あたり $2）。実行前に想定費用が出ます。 セットの設定に書いた固有名詞・場面の説明と話者の名前は、そのまま手がかりとして渡ります。 結果はいまの字幕をすべて置き換えます（直前の edit.json は backup/ に退避。⌘Z では戻りません）。 動画だけ入れたセットでも実行できます。

    無料で済ませたいときは Gemini を使わず、先にローカルで文字起こしします。
    python -m traccia transcribe 動画.mp4 --diarize --split-speakers
    できた dest/<名前>/ をそのまま素材フォルダに置けばセットになります。

    API キーと費用
    「設定」で API キー・使う / 使わない・モデル・今月の上限を決めます。 キーは ~/.traccia/config.json に本人だけが読める権限で保存され、素材フォルダには入りません。 キーを入れただけでは動きません。「使う」に切り替えたときだけ動きます。 これまでの費用も同じ画面に出ます。ただしそれは手元の見積もりで、実費は Google のコンソールが正本です。

    保存先
    編集内容は <セット>/<名前>.edit.json、書き出しは <セット>/export/ です。 元の .srt は書き換えません。
